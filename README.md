# Spotify App 🎵

## Description

Petite application web réalisée en TypeScript utilisant la Spotify Web API.

## Fonctionnalités

- Connexion avec Spotify
- Affichage du profil utilisateur
- Affichage des artistes suivis
- Recherche de morceaux
- Lecteurs Spotify intégrés

## Technologies

- TypeScript
- HTML / CSS
- Spotify Web API
- Vite

## Installation

```bash
npm install
npm run dev
```
